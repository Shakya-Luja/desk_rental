Desk Rental Management System

A web-based Desk Rental Management System developed as a BCA 4th Semester academic project.

The system allows users to view available desks, make bookings, manage their bookings, and make payments. Administrators can manage desks, users, bookings, and payment records through an admin panel.

Technologies Used
HTML
CSS
Bootstrap
PHP
MySQL
XAMPP

Features
User Features
User Registration
User Login and Logout
View Available Desks
View Desk Details
Book a Desk
View My Bookings
View Booking Status
Make Payment for Approved Bookings

Admin Features
Admin Login
Admin Dashboard
Manage Desks
Add, Edit and Delete Desks
Manage Users
Manage Bookings
Approve or Reject Bookings
View Payment Records
View System Statistics

Database
The system uses MySQL to store and manage:

Users
Desks
Bookings
Payments
